# LagSlice ⚡ — بهینه‌ساز استریم

بهینه‌ساز استریم ویندوز برای اینترنت ایران — ساخته‌شده برای استریمرهای گیمر (CS2):
پهنای باند و سرعت آپلود را بین بازی و استریم (MeldStudio + سرورهای MasterStream) مدیریت می‌کند
تا تأخیر ویور زیر ۲۰ ثانیه بماند، و برنامه‌های الکیِ اینترنت‌خور را با یک کلیک می‌بندد.

## LagSlice چه کار می‌کند؟

- **مدیریت پهنای باند** بین گیم و استریم — اولویت‌بندی ترافیک تا استریم قربانی بازی (یا برعکس) نشود
- **پایش زنده‌ی تأخیر ویور**: آپلود/دانلود، پینگ و جیتر سرور استریم + برآورد ریسک تأخیر نسبت به بیت‌ریت
- **«حالت استریم»**: بستن همه‌ی برنامه‌های اینترنت‌خور خارج از لیست امن با یک کلیک
- **لیست امن قابل ویرایش**: برنامه‌هایی که هرگز نباید بسته شوند
- رابط کاملاً **فارسی و راست‌چین** با تم تیره‌ی نئونی بر اساس لوگوی برنامه

# LagSlice ⚡ — Stream Optimizer

A Windows stream optimizer built for Iran's internet — made for gamer streamers (CS2):
it manages bandwidth and upload speed between the game and the stream
(MeldStudio + MasterStream servers) to keep viewer delay under 20 seconds,
and kills bandwidth-hogging apps with one click.

## What LagSlice does

- **Bandwidth management** between game and stream — traffic prioritization so neither starves the other
- **Live viewer-delay monitoring**: upload/download, stream-server ping and jitter, plus delay-risk estimation relative to bitrate
- **"Stream Mode"**: close every bandwidth-hogging app outside the safe list with one click
- **Editable safe list**: apps that must never be closed
- Fully **Persian, right-to-left** interface with a dark neon theme based on the app logo

## Download & run

- Download the latest release from the **Releases** section of this repo; the exe is portable — no installation needed.
- For full functionality (closing apps and managing the network), run it as **Administrator**.

## Requirements

- Windows 10 or 11, 64-bit
- Administrator rights for full functionality (without them, the app runs in limited mode)
