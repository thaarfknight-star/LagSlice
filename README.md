# LagSlice ⚡ (نسخه‌ی Rust)

بازنویسی LagSlice از پایتون/PyQt6 به **Rust + Tauri 2** — برنامه‌ی ویندوزی مدیریت پهنای‌باند و آپلود بین گیم (بیشتر CS2) و استریم (Meld Studio + سرورهای MasterStream)، با رابط فارسی راست‌به‌چپ و اجرای با دسترسی ادمین.

## تغییرات نسخه‌های اخیر

- **نسخه‌ی 0.9.11 — رله‌ی دوحالته:** انتخاب از پنل رله، حتی وسط استریم: «بدون تأخیر» (نردبان تطبیقی ۰٫۹٫۹) یا «بیت‌ریت ثابت» (خط تأخیر ۲٫۵ ثانیه‌ای + سقف سن ۵ ثانیه، بدون نردبان و سطل — خروجی با نرخ ورودی و ثابت).
- **نسخه‌ی 0.9.10 — رفع مرگ خاموش رله:** افتادن نخ رله دیگر پنل را روی «در حال اجرا» گیر نمی‌اندازد و بی‌خطا نمی‌ماند — پیامش در پنل می‌نشیند و رله قابل ری‌استارت می‌شود؛ سطر پایان سشن در لاگ هم نتیجه (توقف تمیز/خطا) را ثبت می‌کند.
- **نسخه‌ی 0.9.9 — جداسازی خواندن از نوشتن + پله‌ی ۵۰۰۰:** نخ خواننده‌ی جدا Meld را تهاجمی می‌خواند و در صف مشترک می‌ریزد؛ نخ پمپ با سقف توکن می‌فرستد و اضافه با حذف GOPهای کهنه دفع می‌شود تا تأخیر حول ۴ ثانیه بماند. نردبان: ۸۰۰۰/۶۰۰۰/۵۰۰۰/۴۰۰۰/۲۵۰۰/۱۵۰۰.
- **نسخه‌ی 0.9.8 — صعود میانه‌ای نردبان رله:** صعود وقتی است که از ۳ پروب اخیر دست‌کم ۲ پروب بالای پله‌ی بالاتر × ۱٫۰۵ باشند، تا روی مسیر پرنوسان روی کف ۱۵۰۰ قفل نشود (لاگ 0.9.7 دقیقاً همین قفل را نشان داده بود).
- **نسخه‌ی 0.9.7 — لاگ رله:** هر ۵ ثانیه یک نمونه از عددهای رله در فایل `LagSlice-relay-log.csv` (دسکتاپ یا Documents) ذخیره می‌شود و مسیرش در پنل نوشته می‌شود تا برای تحلیل تأخیر فرستاده شود.
- **نسخه‌ی 0.9.6 — سقف سن صف رله:** GOP قدیمی‌تر از ۴ ثانیه دور انداخته می‌شود تا تأخیر ویور با کندشدن تخلیه تا دقیقه رشد نکند؛ سن صف و نرخ واقعی تخلیه هم در پنل وضعیت دیده می‌شوند.
- **نسخه‌ی 0.9.5 — رفع هندشیک رله با Meld:** سوکت پذیرفته‌شده بعد از accept به blocking برمی‌گردد تا timeout هندشیک روی ویندوز واقعاً اعمال شود؛ بنر کهنه‌ی «رله شروع شد» هم با توقف رله پاک می‌شود.
- **نسخه‌ی 0.9.4 — رفع سفیدشدن پنجره:** جاروی برنامه‌های انتخاب‌نشده دیگر موتور نمایش خود برنامه و هلپر آپدیت را نمی‌کشد.
- **نسخه‌ی 0.9.3 — رله‌ی تطبیقی RTMP + راهنمای داخل‌برنامه‌ای:** Meld با Custom RTMP به رله‌ی لوکال می‌فرستد و رله بیت‌ریت خروجی به Kick را تطبیقی تنظیم می‌کند تا نوسان شبکه به تأخیر تبدیل نشود؛ صفحه‌ی «راهنما» کل برنامه را آموزش می‌دهد. (منتشر شده.)

## قابلیت محوری: رزرو آپلود برای هر برنامه

- مانیتورینگ زنده‌ی نرخ آپلود/دانلود هر پروسه (EStats ویندوز + IP Helper)
- **رزرو آپلود برای استریم:** سهم Meld Studio کنار گذاشته می‌شود و بقیه‌ی برنامه‌ها خودکار سقف می‌گیرند
- سقف دستی per-app از جدول برنامه‌ها
- پیاده‌سازی سقف‌ها با Windows Policy-based QoS (پالیسی رجیستری در `HKLM\SOFTWARE\Policies\Microsoft\Windows\QoS`) — فقط پالیسی‌های با پیشوند `LagSlice-` ساخته می‌شوند و هنگام خروج برنامه همه پاک می‌شوند
- پینگ سرورهای MasterStream با ICMP

> نکته‌ی فنی صادقانه: shaping لحظه‌ای per-flow درایور کرنل امضاشده می‌خواهد و فاز دو است؛ فاز اول همین مکانیزم پالیسی داخلی ویندوز است.

## ساخت

```bash
cd src-tauri
cargo build --release --target x86_64-pc-windows-gnu   # کراس از لینوکس
# یا روی ویندوز: cargo tauri build
```
