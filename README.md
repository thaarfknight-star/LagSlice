# LagSlice ⚡

بهینه‌ساز استریم ویندوز برای اینترنت ایران.

- مدیریت پهنای باند بین گیم (CS2) و استریم (MeldStudio + سرورهای MasterStream)
- بستن برنامه‌های اینترنت‌خور با لیست امن قابل‌ادیت
- هدف: نگه داشتن تأخیر ویور زیر ۲۰ ثانیه
- رابط فارسی، تم تیره‌ی نئونی

## بیلد

هر پوش به `main` به‌صورت خودکار exe قابل‌حمل (portable) می‌سازد (GitHub Actions → Artifacts).
نقطه‌ی ورود: `app/main.py` — اجرا همیشه با دسترسی ادمین (UAC) چون برای مدیریت پردازش‌ها و شبکه لازم است.
