# LagSlice ⚡ — بهینه‌ساز استریم

بهینه‌ساز استریم ویندوز برای اینترنت ایران — ساخته‌شده برای استریمرهای گیمر (CS2):
پهنای باند و سرعت آپلود را بین بازی و استریم (MeldStudio + سرورهای MasterStream) مدیریت می‌کند
تا تأخیر ویور زیر ۲۰ ثانیه بماند، و برنامه‌های الکیِ اینترنت‌خور را با یک کلیک می‌بندد.

## LagSlice چه کار می‌کند؟

- **مدیریت پهنای باند** بین گیم و استریم — اولویت‌بندی ترافیک تا استریم قربانی بازی (یا برعکس) نشود
- **پایش زنده‌ی تأخیر ویور**: آپلود/دانلود، پینگ و جیتر سرور استریم + برآورد ریسک تأخیر نسبت به بیت‌ریت
- **«حالت استریم»**: بستن همه‌ی برنامه‌های اینترنت‌خور خارج از لیست امن با یک کلیک
- **لیست امن قابل ویرایش**: برنامه‌هایی که هرگز نباید بسته شوند (در `app/safelist.json` ذخیره می‌شود)
- رابط کاملاً **فارسی و راست‌چین** با تم تیره‌ی نئونی بر اساس لوگوی برنامه

## وضعیت نسخه‌ی 0.1.0

- رابط فارسی راست‌چین با تم تیره‌ی نئونی (بر اساس لوگو)
- داشبورد: پایش زنده‌ی آپلود/دانلود/پینگ/جیتر + برآورد ریسک تأخیر ویور نسبت به بیت‌ریت
- دکمه‌ی «حالت استریم»: بستن همه‌ی اینترنت‌خورهای خارج از لیست امن
- تب «برنامه‌ها»: لیست پردازه‌ها (CPU/حافظه/وضعیت) + بستن تکی یا گروهی
- تب «لیست امن»: قابل ویرایش، ذخیره در `app/safelist.json`

## نیازمندی‌ها

- ویندوز ۱۰ یا ۱۱ نسخه‌ی ۶۴ بیتی
- **اجرا با دسترسی ادمین (Administrator)** — برای بستن پردازه‌ها و مدیریت شبکه لازم است؛
  بدون دسترسی ادمین برنامه در حالت محدود اجرا می‌شود
- نصب هیچ‌چیز لازم نیست — نسخه‌ی اجرایی portable است و همه‌ی وابستگی‌ها داخل فایل exe باندل می‌شوند

## اجرا (حالت توسعه)

```bat
pip install -r requirements.txt
python main.py
```

## بیلد

هر پوش به `main` به‌صورت خودکار exe قابل‌حمل (portable) می‌سازد (GitHub Actions → Artifacts).

ساخت دستی:

```bat
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name LagSlice --icon logo/lagslice.ico main.py
```

خروجی در پوشه‌ی `dist` ساخته می‌شود. همه‌ی وابستگی‌ها (PyQt6 و psutil) داخل exe باندل می‌شوند؛
روی سیستم کاربر نهایی چیزی نصب نمی‌شود.

## ساختار

```
main.py            لانچر (نقطه‌ی ورود)
app/lagslice/
  netmon.py      پایش شبکه (ترد): آپلود/دانلود/پینگ/جیتر + برآورد تأخیر
  procman.py     مدیریت پردازه‌ها: شناسایی اینترنت‌خورها، بستن امن، لیست امن
  ui/theme.py          تم نئونی
  ui/main_window.py    پنجره‌ی اصلی
logo/            لوگوی نهایی (lagslice-logo-transparent.png + lagslice.ico)
```
