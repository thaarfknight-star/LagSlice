# LagSlice ⚡ — بهینه‌ساز استریم (ویندوز)

برنامه‌ی ویندوزی (PyQt6) برای استریمرهایی با اینترنت ضعیف/ناپایدار ایران:
پهنای باند را بین گیم (CS2) و استریم (MeldStudio + سرورهای MasterStream) مدیریت می‌کند
و هدفش نگه داشتن تأخیر ویور زیر ۲۰ ثانیه است.

## امکانات نسخه 0.1.0
- 📊 پایش لحظه‌ای آپلود/دانلود + پینگ و جیتر سرور استریم
- 🚦 وضعیت تخمینی تأخیر ویور بر اساس پایداری آپلود (خوب / لب مرز / بحرانی)
- 🔥 «حالت استریم»: بستن برنامه‌های اینترنت‌خور (مرورگر، تورنت، سینک ابری، لانچرها…)
- 🛡 لیست امن پیش‌فرض قابل ویرایش — این برنامه‌ها هرگز بسته نمی‌شوند
- 🌐 رابط فارسی راست‌چین با تم تیره نئونی (بر اساس لوگو)

## اجرا
```bat
pip install -r requirements.txt
python -m lagslice.main
```
برای بستن برنامه‌ها، با **Run as administrator** اجرا کن (در غیر این صورت فقط پایش کار می‌کند).

## بیلد portable
```bat
pip install pyinstaller
pyinstaller lagslice.spec
```
خروجی در `dist/LagSlice/` — بدون نیاز به نصب.

## نکته‌ی صادقانه
تأخیر واقعی ویور را نمی‌شود از روی PC اندازه گرفت؛ LagSlice «ریسک» بالا رفتن
تأخیر را از روی پایداری آپلود نسبت به بیت‌ریت استریم برآورد می‌کند و هشدار می‌دهد.
